# Portfolio demo assets

The existing [Vercel demonstration](https://enterprise-analytics-copilot.vercel.app/)
is an interactive recorded frontend replay, not a hosted model-backed API.
No video recording is distributed in this repository.

For a short walkthrough:

1. Select the Henkel sales example and inspect the reported figure and source.
2. Open Sources & checks to see the distinction between a checked finding and
   illustrative summary wording.
3. Select the Mercedes-Benz price-only question to see the source limitation:
   volume, structure and net pricing are disclosed as a combined bridge item.

The [screenshots](../screenshots/README.md) show the same recorded interface.
The separate public Docker demo computes supported numerical responses with a
deterministic fake provider; the opt-in four-role backend is not the hosted demo.
