# Product screenshots

Screenshots show the approved interface in the frontend-only recorded-demo mode.
They are browser-content captures, without address bars, tabs or developer tools.
The hero is a workflow illustration; the recorded answer is not a live model run.
Temporary responsive capture grids are Git-ignored and are not published.

Public images: `product-overview.png`, `product-overview-dark.png`,
`supported-analysis.png`, `evidence-inspector.png`, `governed-refusal.png`.

Use `npm run build:demo`, `npm run preview`, and `npm run release:smoke` from
`frontend/` to reproduce the review captures. Review images before promoting
them out of `temporary/` into public assets.
