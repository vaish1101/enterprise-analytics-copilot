# Reproducible demonstration plan

The existing [Vercel interface](https://enterprise-analytics-copilot.vercel.app/) is a recorded frontend replay. Reuse it for UI demonstration, not proof of live agents or current diagnostic completeness. Its pinned build, screenshots and remaining boundaries are described in [final release status](final_release_status.md).

## Public numerical demo

Start the documented Docker public-demo target. Ask “What were Henkel H1 2026 sales?” Inspect the reported 10,348 EUR million, claim lineage and verification. This is deterministic fake-provider behavior, not a live AI call. Ask for organic-growth definition: excluded documentary evidence must cause refusal, not fabricated reporting.

## Authorized local engineering demo

With the approved corpus and pgvector, explicitly construct the experimental C API factory with application-owned provider/retriever factories. Use a disclosed scripted provider for a zero-spend engineering demonstration; label every trace as scripted rather than LLM reasoning.

1. Supported KPI: Henkel H1 2026 sales.
2. Supported explanation: Mercedes-Benz Vans adjusted EBIT Q2 2026; inspect slide 11 evidence and the unsplit combined category.
3. Mixed-page support: Henkel group organic-sales-growth drivers H1 2026; inspect the unchanged TABLE source and admitted prose span.
4. PARTIAL: growth-rate change without a specified comparison; show verified numbers and unresolved comparison, not a fabricated explanation.
5. Unsupported request: Mercedes-Benz Cars price-only EBIT attribution; explain the combined source category rather than an infrastructure error.

Use actual returned results and trace records. Do not edit claim IDs, citations, outcomes or recordings to imply success. A deterministic completion repair is not an autonomous agent decision.
