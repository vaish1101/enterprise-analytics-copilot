## Acquisition and redistribution

Only manifest-listed official HTTPS sources are eligible. Redirect, signature,
media and checksum checks operate inside the ignored raw boundary. Unexpected
or changed files fail for review rather than silently replacing approved data.
Publisher access controls are not bypassed.

No open redistribution license is assumed. Raw reports/workbooks, full extracted
text, source-derived corpora, embeddings and indexes remain excluded. The public
demo uses reviewed derived figures and metadata, not fabricated source paragraphs.
